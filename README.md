## 기술 스택

- **Framework**: Next.js 16 (App Router, Turbopack) · React 19 · TypeScript
- **Styling**: Tailwind CSS v4 (모바일 퍼스트)
- **Fonts**: Noto Serif KR (제목) · Noto Sans KR (본문) — `next/font/google`
- **Icons**: lucide-react
- **배포**: Vercel

## 주요 기능

- 일자별 타임라인 일정 (미술관 · 식사 · 이동을 다른 모양으로 구분)
- 각 스팟 구글맵 길찾기 버튼
- 일자별 식사 · 숙소 정보, 이전 · 다음 일차 이동
- 비짓재팬웹 안내 및 일본 내 연락처 입력값 복사
- 글자 크기 조절 (5060 세대 접근성 고려)
- 인쇄 / PDF 저장
- 하단 탭 네비게이션

## 로컬 실행

**Node.js 22.12 이상**이 필요합니다. (그보다 낮은 버전에서는 Tailwind CSS가 `magic-string` ESM 모듈을 불러오지 못해 `globals.css` 에러가 납니다.)

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) 접속

## 일정 수정 방법

일정 데이터는 모두 `lib/itinerary.ts` 한 파일에 있습니다. 홈의 "일정 한눈에 보기"와 일자별 페이지가 이 파일을 함께 사용합니다.

각 스팟은 `kind`에 따라 다르게 표시됩니다.

| kind | 표시 |
|---|---|
| `airport` | 공항 카드 |
| `museum` | 미술관 카드 (`exhibition`에 특별전 이름) |
| `free` | 자유시간 카드 (`options`에 추천 장소 목록) |
| `meal` | 식사 한 줄 |
| `move` | 이동 점선 상자 (`description`에 소요 시간) |

투어 요약 · 포함/불포함은 `components/home/`, 여행 정보 · 비짓재팬웹은 `app/info/page.tsx`와 `components/info/VisitJapanWeb.tsx`에서 수정합니다.

## 이미지 추가 방법

1. `public/images/` 폴더에 이미지를 넣습니다.
2. `lib/itinerary.ts`에서 해당 스팟의 `imagePath`에 경로를 적습니다. (예: `imagePath: "/images/senju.jpg"`)

이미지 파일이 없으면 사진 영역 없이 카드만 표시됩니다.
